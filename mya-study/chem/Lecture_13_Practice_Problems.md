## Answer Key

**1. B.** Eₙ = −R_E Z²/n² gives exactly the Bohr energies, but in the Schrödinger picture quantization is a natural result: only whole-number standing waves fit (2πr = nλ). Bohr had to assume quantized angular momentum.

**2. C.** Eₙ = −R_E Z²/n² = −(2.18 × 10⁻¹⁸ J)(1²)/3² = −2.42 × 10⁻¹⁹ J. −7.27 × 10⁻¹⁹ J divides by n instead of n²; the energy of a bound electron is always negative.

**3. A.** Z = 3 and n = 1: E = −(2.18 × 10⁻¹⁸)(3²)/1² = −1.96 × 10⁻¹⁷ J. −6.54 × 10⁻¹⁸ J forgets to square Z.

**4. D.** Z = 2 and n = 2: E = −(2.18 × 10⁻¹⁸)(2²)/2² = −2.18 × 10⁻¹⁸ J. −5.45 × 10⁻¹⁹ J uses Z = 1 (hydrogen); −1.09 × 10⁻¹⁸ J forgets to square Z; −8.72 × 10⁻¹⁸ J forgets to divide by n².

**5. A.** ΔE = R_E Z²(1/2² − 1/3²) = (2.18 × 10⁻¹⁸)(4)(5/36) = 1.21 × 10⁻¹⁸ J. λ = hc/ΔE = (6.626 × 10⁻³⁴)(3.00 × 10⁸)/(1.21 × 10⁻¹⁸) = 1.64 × 10⁻⁷ m = 164 nm. 656 nm is the same transition in hydrogen (Z = 1); 328 nm uses Z instead of Z².

**6. D.** For hydrogen (and any one-electron ion) the energy depends only on n, so all orbitals with the same n are degenerate: E(3s) = E(3p) = E(3d). Orbitals with different n have different energies.

**7. B.** The orbital separates into a radial wave function R(r), which depends only on the distance from the nucleus, multiplied by an angular wave function Y(θ, φ), using spherical polar coordinates.

**8. A.** The energy of a hydrogen orbital depends on n alone, but the wave function is described by three quantum numbers: n, l and mₗ. (A Bohr orbit is characterized by n only.)

**9. C.** n determines size and energy, l determines shape, and mₗ determines orientation.

**10. B.** l = 0, 1, …, (n − 1), so for n = 3, l = 0, 1, 2 (3s, 3p, 3d). There are n types of orbitals for principal quantum number n.

**11. D.** mₗ = l, l − 1, …, 0, …, −l, so for l = 2, mₗ = +2, +1, 0, −1, −2: (2l + 1) = 5 values.

**12. D.** l can only go up to n − 1. For n = 2, l can be 0 or 1, so l = 2 is not allowed. The other sets all satisfy l ≤ n − 1 and |mₗ| ≤ l.

**13. A.** n = 3 allows l = 1, and l = 1 allows mₗ = −1. (1, 1, 0) has l = n; (3, 3, 1) has l = n; (2, 1, 2) has |mₗ| > l.

**14. C.** The total number of orbitals in a shell is n² = 4² = 16 (one 4s, three 4p, five 4d, seven 4f). 32 is the number of electrons the shell can hold (2n²).

**15. B.** A subshell has (2l + 1) orbitals: 2(3) + 1 = 7 (the f orbitals).

**16. D.** l = 0, 1, 2, 3 correspond to s, p, d, f. n = 4 with l = 2 is a 4d subshell.

**17. A.** A d orbital needs l = 2, which requires n ≥ 3, so 2d cannot exist. (Similarly there is no 1p and no 3f.)

**18. C.** There are n subshells in shell n: for n = 3, l = 0, 1, 2 give 3s, 3p and 3d. 3f would need l = 3, which is not allowed for n = 3. The shell has 9 orbitals, but only 3 subshells.

**19. B.** |L| = √[l(l + 1)] ħ. For a d electron, l = 2: |L| = √(2 × 3) ħ = √6 ħ.

**20. A.** The z-component is mₗħ. For l = 1, mₗ = +1, 0, −1, giving +ħ, 0 and −ħ. The orientation is quantized, so values in between are not allowed. (√2 ħ is the magnitude of L, not its z-component.)

**21. B.** The magnitude of L and its z-component (mₗħ) are fixed, but the x- and y-components are indefinite, so the vector could point anywhere on a cone about the z-axis.

**22. D.** For s orbitals, l = 0, so |L| = √[0(0 + 1)] ħ = 0.

**23. A.** For an s orbital, Ψ depends only on r and not on θ or φ, so it looks the same in every direction.

**24. C.** All s orbitals have a non-zero value of Ψ at the nucleus. For p, d and f orbitals Ψ is zero at the nucleus.

**25. D.** A node is where the wave function passes through zero and changes sign, so the probability of finding the electron there is zero.

**26. B.** The number of radial nodes increases with n: 1s has 0, 2s has 1 and 3s has 2 (n − 1 for s orbitals).

**27. C.** A p orbital has two lobes of opposite sign of Ψ (shown with + and − or with shading) separated by an angular node, so Ψ is zero at the nucleus. There is no 1p orbital; p orbitals first appear at n = 2, three per subshell.

**28. A.** The solutions with mₗ = +1, 0, −1 can be combined into an equivalent set of three orbitals pointing along the perpendicular x, y and z axes: px, py and pz.

**29. D.** d orbitals need l = 2, so they first appear at n = 3. There are five (mₗ = +2, +1, 0, −1, −2), and each has two angular nodes (for one of them, a cone-shaped node, the doughnut). They matter for the transition metals.

**30. A.** f orbitals need l = 3, so they first appear at n = 4. There are seven (mₗ = +3 to −3), each with three angular nodes and Ψ = 0 at the nucleus. They matter for the lanthanides and actinides.

**31. B.** Because Ψ never quite reaches zero far from the nucleus, an orbital is drawn as a boundary surface inside which the electron has a specific probability of being found, typically 90%.

**32. C.** Ψ² is the probability at a point. The radial distribution function, 4πr² × R²(r), is the probability of finding the electron anywhere in a thin spherical shell of radius r.

**33. D.** Ψ² for 1s is greatest at the nucleus, but the radial distribution function is zero at r = 0 and peaks at r = a₀ (0.529 Å), the Bohr radius. So the most likely single point is the nucleus, while the most likely distance is a₀.

**34. A.** The shell volume 4πr² dr goes to zero as r goes to zero, so even though Ψ² is large at the nucleus for an s orbital, the radial probability there is zero.

**35. C.** The distance of maximum probability increases with n, and the energy increases as the number of radial nodes increases (0, 1, 2 for 1s, 2s, 3s).
